# 🎮 遊戲快速通關工具 - 使用說明

## 📋 功能概述

這是一個用於第56屆全國技能競賽北區訓練的快速通關工具。只需將腳本貼到遊戲頁面的 Console 中，即可自動完成遊戲！

## 🎯 支援的遊戲

1. **數字挑戰** - 按升序點擊數字
2. **記憶挑戰** - 按升序點擊數字
3. **反應力測試** - 測試反應時間
4. **打地鼠** - 30秒打地鼠挑戰
5. **滑動拼圖** - 數字拼圖遊戲

## 🚀 使用方法

### 步驟 1：開啟遊戲頁面
在瀏覽器中開啟任何一個遊戲的 index.html 檔案

### 步驟 2：開啟開發者工具
- **Windows/Linux**: 按 `F12` 或 `Ctrl + Shift + I`
- **Mac**: 按 `Cmd + Option + I`

### 步驟 3：切換到 Console 分頁
在開發者工具中找到「Console」（控制台）分頁

### 步驟 4：貼上腳本
1. 開啟 `game-auto-complete.js` 檔案
2. 複製所有程式碼（Ctrl+A → Ctrl+C）
3. 貼到 Console 中（Ctrl+V）
4. 按 Enter 執行

### 步驟 5：使用控制面板
腳本執行後會自動彈出一個漂亮的控制面板：

#### 控制面板功能
- **遊戲名稱顯示**：自動辨識當前遊戲
- **模式選擇**：根據遊戲提供不同模式
- **狀態顯示**：即時顯示執行狀態
- **關閉按鈕**：右上角可關閉面板

## 🎨 模式說明

### 數字挑戰 / 記憶挑戰
- ✅ **通關模式（贏）**：自動按正確順序點擊數字
- ❌ **失敗模式（輸）**：故意點擊錯誤順序

### 反應力測試
- ✅ **完成測試（贏）**：在畫面變綠後快速點擊，模擬真人反應時間
- ❌ **全部失敗（輸）**：故意在變綠前點擊（太早）

### 打地鼠
- 🎯 **自動打地鼠**：自動追蹤並點擊出現的地鼠，獲得高分

### 滑動拼圖
- 🧩 **自動解拼圖**：自動移動方塊完成拼圖

## ⚙️ 特色功能

### 🤖 模擬真人操控
- **隨機延遲**：每次點擊都有隨機延遲（200-800ms）
- **自然操作**：模擬真實玩家的操作節奏
- **反應時間**：反應力測試模擬真實反應（150-300ms）

### 🎨 美觀介面
- **漸層背景**：使用不同顏色漸層區分模式
- **動畫效果**：平滑的進入動畫和互動效果
- **即時狀態**：清楚顯示當前執行狀態
- **響應式設計**：適應不同螢幕尺寸

### 🔍 智慧辨識
- **自動檢測**：自動辨識當前是哪個遊戲
- **動態按鈕**：根據遊戲生成對應的操作按鈕
- **錯誤處理**：優雅處理各種異常情況

## 📝 使用範例

### 範例 1：數字挑戰（贏）
```
1. 開啟遊戲頁面
2. 貼上腳本
3. 點擊「✅ 通關模式（贏）」
4. 腳本會自動：
   - 分析數字
   - 按升序點擊
   - 完成挑戰
```

### 範例 2：反應力測試（輸）
```
1. 開啟遊戲頁面
2. 貼上腳本
3. 點擊「❌ 全部失敗（輸）」
4. 腳本會自動：
   - 點擊開始按鈕
   - 在每回合故意太早點擊
   - 導致所有回合失敗
```

### 範例 3：打地鼠
```
1. 開啟遊戲頁面
2. 貼上腳本
3. 點擊「🎯 自動打地鼠」
4. 腳本會自動：
   - 開始遊戲
   - 快速點擊出現的地鼠
   - 獲得高分
```

## 🎯 技術細節

### 自動化原理
- **DOM 操作**：直接操作網頁元素
- **事件模擬**：模擬真實的點擊事件
- **狀態監控**：使用 MutationObserver 監控遊戲狀態
- **異步執行**：使用 async/await 處理延遲

### 顏色主題
| 元素 | 顏色漸層 |
|------|----------|
| 面板標題 | 紫色漸層（#667eea → #764ba2）|
| 遊戲資訊 | 粉紅漸層（#f093fb → #f5576c）|
| 通關按鈕 | 綠色漸層（#43e97b → #38f9d7）|
| 失敗按鈕 | 橙粉漸層（#fa709a → #fee140）|
| 一般按鈕 | 藍色漸層（#4facfe → #00f2fe）|

## 💡 注意事項

1. **腳本重複執行**：如果已執行腳本，重新執行會創建新面板
2. **遊戲頁面**：請確保在正確的遊戲頁面執行
3. **開發者工具**：請勿在執行期間關閉開發者工具
4. **網頁重新整理**：重新整理頁面後需重新貼上腳本

## 🐛 故障排除

### 問題：面板沒有出現
- 檢查是否在正確的遊戲頁面
- 檢查 Console 是否有錯誤訊息
- 嘗試重新整理頁面後再次執行

### 問題：按鈕點擊沒反應
- 檢查遊戲是否已經開始
- 查看狀態區域的訊息
- 檢查 Console 的錯誤訊息

### 問題：自動操作失敗
- 遊戲元素可能已更新
- 嘗試重新整理頁面
- 查看 Console 的詳細錯誤
